# 纸予统一文字色阶

以 Claude Design 页面提取的 21 个中性灰阶为基础，不再对中性色做 HSL 调色。050 在底层统一提亮为 #fdfcfa，所有引用该色阶的区域共同跟随，不单独覆盖编辑器或插件背景。浅色模式沿用该页面的背景、文字和边框角色；深色模式使用相同色值安排明暗层级。正文、标题、属性、图标、侧栏、设置、卡片、菜单、边框、代码块、滚动条与通知均共用这套变量。

来源：[Claude Design](https://claude.com/product/design) 的页面 CSS 自定义属性 `--swatch--gray-*`，提取于 2026-09-30。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 主背景 | #fdfcfa | #1f1e1d |
| 侧栏、属性卡片背景 | #f5f4ed | #262624 |
| 第三级背景 | #f0eee6 | #30302e |
| 正文、标题 | #141413 | #e8e6dc |
| 次级文字、引用、标点 | #87867f | #b0aea5 |
| 弱提示文字 | #87867f | #87867f |
| 普通分隔边框 | #e8e6dc | #3d3d3a |
| 悬浮边框 | #d1cfc5 | #4d4c48 |
| 输入框边框 | #b0aea5 | #73726c |
| 目录、菜单、顶部标签、辅助面板和图标 | #73726c | #87867f |
| 辅助区域悬浮、聚焦文字 | #5e5d59 | #b0aea5 |

深色模式保留网站 `.u-theme-dark-2` 的背景和边框；文字按用户反馈使用正文 gray-200、次级 gray-400、辅助 gray-500，属性值使用次级文字。050 保持网站原值 #faf9f5。完整原始色值见 `claude-design-color-tokens.json`。强调文字跟随用户主题色，强调色上的按钮文字、图标与开关圆点保持白色。

源头：`src/color-schemes/zhiyu.scss` 中的 `--zhiyu-text-*`，映射到 Obsidian 的 `--text-normal`、`--text-muted`、`--text-faint`。

编辑器与阅读视图直接使用 `--text-normal`。正文、标题和属性文字保留中性色阶。纸予的默认主题色在浅色、深色模式下均为 `#ff6924`，用于按钮、开关背景、聚焦边框和内外部链接；强调背景上的文字、图标、开关圆点固定为白色，不根据强调色的饱和度切换。

其他语义色围绕主题橙搭配，采用更柔和的饱和度。参考 Primary 按 Markdown 结构分色的方法，笔记与 Prism 对话共用下表；颜色由文字结构决定，CSS 不会识别纯文本路径。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 主题交互、链接 | #ff6924 | #ff6924 |
| 粗体强调：主题色 | #ff6924 | #ff6924 |
| 错误提示：红色 | #b53333 | #df6666 |
| 行内代码、路径：琥珀橙 | #b96a36 | #e8ad7f |
| 警告：燕麦色 | oat 40% + gray-650 60% | oat #e3dacc |
| 斜体、标签：柔和蓝 | #496f9f | #9bbadd |
| 辅助、出链：灰紫 | #826797 | #beadd4 |
| 成功：矿物绿 | mineral 75% + gray-650 25% | cactus #bcd1ca |

加粗斜体使用正文色，删除线使用弱提示色。普通／加粗／斜体高亮分别用淡金／淡桃橙／淡蓝背景；标签和行内代码使用对应色系的浅底，代码块保留语法分色。

本轮通过 Sass 编译并同步到 Vault；按用户要求不做界面检查。插件硬编码的颜色或用户 CSS 仍可能覆盖主题变量。

状态色适配：Claude 网站 CSS 没有命名的 success/warning 角色。成功采用 mineral/cactus，警告采用 oat；浅色文字与 gray-650 混合以保持可读性，状态背景由对应文字变量与主背景混合 10%，悬停为 18%。这些是纸予的语义映射，不是网站原有状态角色。
