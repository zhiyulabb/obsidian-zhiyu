# 纸予统一文字色阶

此表取代旧 Primary 对照页中的纸予文字色值。浅深色共用 HSL 色相 100、饱和度 6%。深色明度由浅色反转（100% - L）：22/38/44 → 78/62/56，不另设偏绿色板。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 正文、标题、链接、强调文字 | #373b35 | #c6cac4 |
| 辅助文字、引用、标点 | #5f675b | #9ca498 |
| 弱提示文字 | #6e7769 | #8d9688 |

源头：`src/color-schemes/zhiyu.scss` 中的 `--zhiyu-text-*`，映射到 Obsidian 的 `--text-normal`、`--text-muted`、`--text-faint`。

编辑器与阅读视图直接使用 `--text-normal`，不再使用独立的编辑器颜色设置。正文、标题和属性文字保留中性色阶。参考 Primary 的语义分工，纸予加粗／内部链接／行内代码使用主绿色，斜体／外部链接使用青色，标签使用蓝色，加粗斜体回到正文色，删除线使用弱提示色。颜色来自现有纸予色板，不新增独立插件色值。普通／加粗／斜体高亮分别用淡黄／淡绿／淡青背景；代码块暂保留中性文字。错误／警告／成功恢复红／橙／绿语义颜色。按钮在强调背景上仍使用适合对比度的文字色。

验证：浅色／深色浏览器渲染检查，含旧编辑器颜色残留场景。尚未进行运行中 Obsidian 全页面检查；插件自行硬编码的色值或用户 CSS 仍可能覆盖主题。
