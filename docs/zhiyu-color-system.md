# 纸予主题颜色系统

本文档记录纸予默认配色的最终颜色角色。表格按“浅色 / 深色”横向对比；同一颜色的 Obsidian 别名合并展示，避免重复罗列。

> 默认主色仅在 Obsidian「外观 → 主题色 → 恢复默认」后生效。用户自定义主题色会覆盖 `--accent-h/s/l`，所有依赖主色的颜色随之变化。

## 2. 主色与交互色

品牌填充与品牌文字分离：浅色主色文字为 `55% 主色 + 45% 正文色`，保证默认主色在白底达到 4.5:1；深色为 `82% 主色 + 18% 白色`。

## 8. 代码语法最终映射

纸予的最终语义覆盖刻意让代码块保持中性，避免整页出现过多竞争色。只有行内代码使用主色。

| 代码内容 | 浅色 | 深色 |
|---|---:|---:|
| 普通、函数、关键字、属性、字符串、标签、值 | `#373B35` | `#C6CAC4` |
| 注释、操作符、标点 | `#5F675B` | `#9CA498` |
| 行内代码 | `#3D8353` | `#92D6A8` |
| 代码块背景 | `#F6F5F3` | `#20241F` |
