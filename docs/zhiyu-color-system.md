## 边界与检查

全屏适配：本机 Obsidian 1.13.7 仅在 `.is-translucent:not(.is-fullscreen)` 为外层绘制半透明底色。主题在半透明全屏时为外层 `.app-container` 和 `.titlebar` 使用同一 `--workspace-background-translucent`，不再用实色挡住背景，不改子面板或几何样式。桌面模糊依赖原生窗口能力，CSS 检查不代表已验证 macOS 全屏 vibrancy。

原生半透明底色默认不透明度：浅色、深色均为 60%，撤回先前 85%／90% 的厚重底色，可在 Style Settings 分别调整。两种模式使用相同透光强度及各自主题底色，不保证感知效果完全相同。不覆盖工作区、侧栏或编辑区背景规则；保留原有布局、圆角、面板边界和聚焦／失焦行为。不改变文字透明度，不额外增加 CSS 模糊。最终桌面合成效果须在 Obsidian 中确认。

辅助文字 `--text-faint`：浅色 #5F655A、深色 #AAA8A1。深色正文、次级文字和标题辅助文字使用暖中性灰，避免在暖炭灰背景上偏绿；绿色语义强调色保持不变。

深色中性背景改为浅色纸张风格对应的暖炭灰：页面 #1C1B19、侧栏 #242320、输入框和悬停 #2D2B28、浮层 #34312D、边框 #403C36。选区和标签仍使用绿色语义色；强调文字、引用块和浅色模式不变。代码底色保持黄色方向，减少橄榄感。

- 用户选定的浅色主绿白底约 4.003:1，低于普通文字 AA 的 4.5:1，不宣称整套主题符合普通文字 AA。检查页保留文字 4.5:1、非文字 3:1 阈值。
- 原生自定义主色可能覆盖两种模式默认值；不会自动生成新的固定辅助色。
- 文章颜色使用固定色值，不以混色、透明覆盖调色。模态遮罩、投影、隐藏动画及用户主动启用的透明窗口、图片/PDF 滤镜保留原用途。
- [方案对照页](color-proposal-v2.html) 的 verifyProposal() 将实际编译结果与冻结的确认方案对比。
- [颜色检查页](color-audit.html)：auditTypography 检查阅读与编辑一致性；auditPrimary 检查主绿与引用块；auditHarmony 检查通用色板和 RGB 别名；auditSurfaces 检查透明度、滤镜和混合模式；auditColors 如实报告对比度不足。
- [完整文章预览](typography-preview.html) 支持 ?mode=dark。浏览器 CSS 检查不等于 Obsidian 实时界面或第三方插件验证。
